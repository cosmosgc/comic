## PHP (Pint / AGENTS.md rules)

1. **[DECLINED 2026-10-19] Run `vendor/bin/pint` repo-wide.** Deliberately not done: the PR checklist requires `--dirty` **on touched files only**, because a repo-wide run reformats untouched code (especially `routes/web.php`). Historical context: ~30 files still drift: dominant fixers are `braces_position` (K&R), `not_operator_with_successor_space` (`! Auth`, `! is_string`), `ordered_imports`, `blank_line_before_statement`, `fully_qualified_strict_types` (use imports, not FQCNs), `concat_space`, `cast_spaces`, `single_quote`, `blank_line_after_namespace`, trailing commas. Affected: controllers (`Analytics`, `Login`, `Page`), middleware, listeners, models (`Analytics`, `Tag`), `Services/Deploy/*`, `MigrationInspector`, `ComicCard`, `bootstrap/app|providers`, `config/auth|database|sanctum`, `database/factories/UserFactory`, 9 migrations, `routes/api|web`, `ComicUploadLimitsTest`.
2. **Explicit return + param types everywhere.** Project rule requires `function foo(...): bool`-style signatures; ~87 controller methods lack them — add `: View|RedirectResponse|JsonResponse|Response` and type route params (`string|int $id`, or model binding `Comic $comic`, `User $user`). Same for remaining model relations/scopes and `readerEngagement(): array`, `popularTags`, `recommended`, `likedPostsFor`.
3. **[DONE 2026-10-19] Constructor promotion.** `CurlFtpTransport` now promotes host/port/username/password/ssl/verifySsl/timeout/freshConnection (with `fromConfig()` for the `config('deploy')` shape); no remaining manual `$this->x = $x` constructors.
4. **[DONE 2026-10-19] Enum keys TitleCase** — `AnalyticsEventType`, `DeployState` and `ChangelogCategory` use TitleCase keys (see `suggestions.md` #5).
5. **PHPDoc over narration.** Keep array-shape PHPDocs (`ChangelogReader`, `FtpDeployer`, `CurlFtpTransport`, `SidebarComposer`, `AdminController`) and extend `@param`/`@return` shapes to uncovered methods; remove trailing inline narrations (`// Default to false`, `// Create the base slug`, emoji comments in `ComicController`, Portuguese string in `PostController`).
6. **Unify conditionals/spacing.** `} elseif` (not `} else if`), `! Auth` / `! file_exists` spacing, single quotes for strings, `single_line_comment_spacing`.
